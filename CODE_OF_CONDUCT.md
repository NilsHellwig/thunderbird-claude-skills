# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, patient and respectful, whatever someone's background or experience.
- Give and accept constructive feedback gracefully. Focus on what is best for the project and its users.
- Harassment, insults, personal or political attacks, and publishing others' private information are not tolerated.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when you represent the project elsewhere.

## Enforcement

Report unacceptable behavior privately to the maintainer, [@NilsHellwig](https://github.com/NilsHellwig), via a GitHub private message or a [private security advisory](https://github.com/NilsHellwig/thunderbird-claude-skills/security/advisories/new) if no other channel fits. All reports are handled confidentially.

The maintainer may remove, edit or reject contributions that violate this code, and may temporarily or permanently ban contributors. This follows the enforcement guidelines of the Contributor Covenant.
